# Портик

Стоическая практика на каждый день. Статический сайт без сервера и сборки: один `index.html`.

Что внутри:

- главная из виджетов: уровень и серия, цитата, утро и вечер, упражнение дня, эксперименты, время, слабая грань, принцип, чтение, слово из словаря. Набор и порядок настраиваются;
- стоические эксперименты: отказ от чего-то или ежедневное действие, таймер, календарь, статистика по неделям;
- уровни и достижения: опыт считается из дневника, экспериментов, словаря и чтения, ничего отдельно не копится;
- утренняя подготовка и вечерний разбор;
- 37 упражнений: античные (Эпиктет, Сенека, Марк Аврелий), двенадцать упражнений из How to Be a Stoic Массимо Пильюччи, недели из A Handbook for New Stoics, практики по мотивам A New Stoicism Лоуренса Беккера;
- добродетель: паутина развития по 4 граням и 18 составляющим, колесо с упражнениями, самооценка;
- учение: десять основоположений стоиков в современном прочтении и своя цитадель принципов;
- учет времени по Сенеке: жизнь в неделях и сколько уходит на пожирателей времени;
- читалка: EPUB, FB2 (в том числе .fb2.zip), TXT и PDF с текстовым слоем на русском и английском, темы как у читалок (светлая, сепия, серая, ночь, черная), размер и шрифт, оглавление, запоминание места;
- параллельное чтение: связываешь оригинал с переводом, и в читалке появляется режим с двумя текстами, главы листаются вместе, сдвиг глав настраивается;
- словарь для английских книг: нажми на слово или выдели фразу, сохрани с переводом и контекстом, выгрузи в Quizlet или CSV;
- дневник с резервной копией в JSON.

Все данные хранятся только в браузере (localStorage и IndexedDB для книг). На сервер ничего не отправляется.

Исключение: когда в английской книге нажимаешь на слово, само это слово уходит в два бесплатных сервиса, [Free Dictionary API](https://dictionaryapi.dev) за значением и транскрипцией и [MyMemory](https://mymemory.translated.net) за переводом. Без интернета или если сервис не ответил, перевод можно вписать руками. У MyMemory без регистрации лимит 5000 символов в день, для отдельных слов этого с запасом.

EPUB с DRM открыть нельзя. Для EPUB нужен iOS 16.4 или новее. PDF разбирается библиотекой pdf.js, она лежит в `vendor/` и работает офлайн; текст из PDF собирается в абзацы по координатам, так что в книгах с колонками или сложной версткой порядок может сбиться. Сканы без текстового слоя не откроются.

## Публикация на GitHub Pages

```bash
git init
git add .
git commit -m "Портик"
git branch -M main
git remote add origin git@github.com:<ник>/portik.git
git push -u origin main
```

Дальше в репозитории: **Settings → Pages → Build and deployment**, Source: **Deploy from a branch**, Branch: **main**, папка **/ (root)**, Save.
Через минуту-две сайт появится по адресу `https://<ник>.github.io/portik/`.

На бесплатном плане GitHub Pages публикует только публичные репозитории, поэтому этот репо публичный. Личных данных в нем нет.

## Иконки на экран «Домой»

Настоящих виджетов у веб-приложений на iPhone нет. Вместо них есть `w.html`: отдельные экраны, которые можно добавить на экран «Домой» как иконки. Ссылки на них лежат в настройках главной (шестеренка). У такой иконки свое хранилище, поэтому туда вынесено только то, что не зависит от дневника: цитата и упражнение дня (считаются от даты), жизнь в неделях и memento mori (цифры зашиты в ссылку).

На Android долгое нажатие на иконку показывает быстрые ссылки: утро, вечер, эксперименты. На любом устройстве работают адреса с `#morning`, `#evening`, `#exp` в конце.

## На iPhone

Открой сайт в Safari, **Поделиться → На экран «Домой»**. Откроется как приложение, без адресной строки, и работает офлайн.

Важно: у приложения с экрана «Домой» свое хранилище, отдельное от Safari. Пользуйся чем-то одним, а данные между ними переноси через **Дневник → Резервная копия**.

## Обновление

Правишь `index.html`, коммитишь, пушишь. Страница грузится сначала из сети, так что обновление приходит при следующем открытии. Если поменял иконки или манифест, подними версию `CACHE` в `sw.js`.

## Файлы

```
index.html              приложение целиком: разметка, стили, логика, контент
manifest.webmanifest    установка на экран «Домой»
sw.js                   офлайн-кэш
icons/                  иконки
vendor/                 pdf.js (Apache 2.0) для разбора PDF
.nojekyll               чтобы Pages отдавал файлы как есть
```

Цитаты древних авторов даны в вольном переводе, идеи современных авторов пересказаны своими словами.
