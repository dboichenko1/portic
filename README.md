# Портик

Стоическая практика на каждый день. Статический сайт без сервера и сборки: один `index.html`.

Что внутри:

- главная из виджетов: уровень и серия, цитата, утро и вечер, упражнение дня, эксперименты, время, слабая грань, принцип, чтение, слово из словаря. Набор и порядок настраиваются;
- стоические эксперименты: отказ от чего-то или ежедневное действие, таймер, календарь, статистика по неделям;
- серия дней: растет, пока заходишь каждый день, и сгорает, если пропустить хотя бы один;
- 30 уровней от новичка до феникса и достижения: опыт считается из дневника, экспериментов, словаря, чтения и дней в приложении, ничего отдельно не копится;
- утренняя подготовка и вечерний разбор;
- 37 упражнений: античные (Эпиктет, Сенека, Марк Аврелий), двенадцать упражнений из How to Be a Stoic Массимо Пильюччи, недели из A Handbook for New Stoics, практики по мотивам A New Stoicism Лоуренса Беккера;
- добродетель: паутина развития по 4 граням и 18 составляющим, колесо с упражнениями, самооценка;
- учение: десять основоположений стоиков в современном прочтении и своя цитадель принципов;
- море философии: карта из восьми островов и 39 пристаней, по которой плывешь на корабле: от милетцев, Гераклита, Парменида, Демокрита и пифагорейцев через Сократа, софистов и киников через Эпикура и скептиков, Будду, Лао-цзы, Конфуция и Гиту, Плотина, Боэция, Аль-Кинди и Фому, Липсия, Декарта, Монтеня, Спинозу, Канта, Милля и Шопенгауэра, Торо, к экзистенциалистам, Франклу, Адо и КПТ. На каждой: кто, главные тезисы, понятия (можно выгрузить в Quizlet), что читать, где школа сходится со Стоей, где спорит и что взять в практику;
- темы оформления: свои светлая и ночная, сепия, и 23 палитры из PyCharm и VS Code (Darcula, Dark Modern, Monokai, Solarized, Dracula, Nord, One Dark, GitHub, Gruvbox, Catppuccin, Tokyo Night и другие);
- учет времени по Сенеке: жизнь в неделях, сколько уходит на пожирателей времени, и живой таймер в стиле Toggl: нажал старт, когда поймал себя на пустом, стоп записал минуты;
- читалка: EPUB, FB2 (в том числе .fb2.zip), TXT и PDF с текстовым слоем на русском и английском, темы как у читалок (светлая, сепия, серая, ночь, черная), размер и шрифт, оглавление, запоминание места;
- параллельное чтение: связываешь оригинал с переводом, и в читалке появляется режим с двумя текстами, главы листаются вместе, сдвиг глав настраивается;
- словарь для английских книг: нажми на слово или выдели фразу, сохрани с переводом и контекстом, выгрузи в Quizlet или CSV;
- дневник с резервной копией в JSON.

Все данные хранятся только в браузере (localStorage и IndexedDB для книг). На сервер ничего не отправляется.

Исключение: когда в английской книге нажимаешь на слово, само это слово уходит в два бесплатных сервиса, [Free Dictionary API](https://dictionaryapi.dev) за значением и транскрипцией и [MyMemory](https://mymemory.translated.net) за переводом. Без интернета или если сервис не ответил, перевод можно вписать руками. У MyMemory без регистрации лимит 5000 символов в день, для отдельных слов этого с запасом.

EPUB с DRM открыть нельзя. Для EPUB нужен iOS 16.4 или новее. PDF разбирается библиотекой pdf.js, она лежит в `vendor/` и работает офлайн; текст из PDF собирается в абзацы по координатам, так что в книгах с колонками или сложной версткой порядок может сбиться. Сканы без текстового слоя не откроются.

## Публикация на GitHub Pages

```bash
git init
git add .
git commit -m "Портик"
git branch -M main
git remote add origin git@github.com:<ник>/portik.git
git push -u origin main
```

Дальше в репозитории: **Settings → Pages → Build and deployment**, Source: **Deploy from a branch**, Branch: **main**, папка **/ (root)**, Save.
Через минуту-две сайт появится по адресу `https://<ник>.github.io/portik/`.

На бесплатном плане GitHub Pages публикует только публичные репозитории, поэтому этот репо публичный. Личных данных в нем нет.

## Иконки на экран «Домой»

Настоящих виджетов у веб-приложений на iPhone нет. Вместо них есть `w.html`: отдельные экраны, которые можно добавить на экран «Домой» как иконки. Ссылки на них лежат в настройках главной (шестеренка). У такой иконки свое хранилище, поэтому туда вынесено только то, что не зависит от дневника: цитата и упражнение дня (считаются от даты), жизнь в неделях и memento mori (цифры зашиты в ссылку).

На Android долгое нажатие на иконку показывает быстрые ссылки: утро, вечер, эксперименты. На любом устройстве работают адреса с `#morning`, `#evening`, `#exp` в конце.

## Настоящие виджеты через Scriptable

Если хочется виджет на экране, который показывает содержимое без открытия приложения, есть обходной путь: бесплатное приложение [Scriptable](https://scriptable.app) умеет делать виджеты из скриптов. Скрипт лежит в `scriptable/portik-widget.js`.

1. Поставь Scriptable из App Store.
2. Открой `scriptable/portik-widget.js`, скопируй весь текст. В Scriptable нажми `+`, вставь, назови скрипт «Портик». В начале впиши адрес своего сайта в `SITE`.
3. На экране «Домой» добавь виджет Scriptable нужного размера, долгим нажатием открой его настройки: Script «Портик», Parameter один из списка ниже. Виджетов может быть сколько угодно, с разными параметрами.

Виджеты от даты, данные берут с сайта один раз и кэшируют:

| Parameter | Что показывает |
|---|---|
| `quote` | цитата дня |
| `exercise` | упражнение дня с шагами |
| `virtue` | грань добродетели дня, составляющая и упражнение |
| `doctrine` | основоположение дня в современном прочтении |
| `harbor` | пристань дня: школа и один из ее тезисов |
| `ritual` | до 15:00 вопросы утра, после вопросы вечера; тап открывает Портик на нужном ритуале |
| `life:1996-03-14:80:16:120` | жизнь в неделях: дата рождения, горизонт, часов бодрствования, минут в день на пустое |
| `memento:1996-03-14:80` | memento mori: сколько прожито и сколько впереди |

Виджеты с твоими данными читают последнюю резервную копию. Сохрани ее из Портика (Дневник, Резервная копия, Сохранить копию) в Файлы, в папку iCloud Drive/Scriptable, и обновляй раз в день или два. Таймеры экспериментов считаются живыми от даты старта, остальное на момент копии:

| Parameter | Что показывает |
|---|---|
| `level` | уровень, опыт, серия дней |
| `exp` | активные эксперименты с таймерами и прогрессом к цели |
| `today` | сводка: серия, уровень, пустое за сегодня, эксперименты, принцип дня |
| `word` | слово дня из твоего словаря с переводом и контекстом |
| `principle` | принцип дня из цитадели |

Тап по любому виджету открывает Портик.

## На iPhone

Открой сайт в Safari, **Поделиться → На экран «Домой»**. Откроется как приложение, без адресной строки, и работает офлайн.

Важно: у приложения с экрана «Домой» свое хранилище, отдельное от Safari. Пользуйся чем-то одним, а данные между ними переноси через **Дневник → Резервная копия**.

## Обновление

Правишь `app.js` или `app.css`, коммитишь, пушишь. Страница грузится из сети, код подтягивается в фоне, так что обновление приходит на второе открытие. Если поменял шрифты, иконки или pdf.js, подними версию `CACHE` в `sw.js`.

## Файлы

```
index.html              каркас страницы и политика безопасности (CSP)
app.js                  логика и контент: упражнения, учение, читалка, эксперименты
app.css                 стили и все темы
theme.js                ставит тему до первой отрисовки
w.html, w.js, w.json    мини-экраны для иконок на «Домой» и данные для виджета Scriptable
fonts/                  Forum и Literata (OFL), подмножества латиница, кириллица, греческий
manifest.webmanifest    установка на экран «Домой», быстрые ссылки
sw.js                   офлайн-кэш: страница и код обновляются в фоне, шрифты и pdf.js из кэша
icons/                  иконки
vendor/                 pdf.js (Apache 2.0) для разбора PDF
scriptable/             скрипт виджета для Scriptable
.nojekyll               чтобы Pages отдавал файлы как есть
```

## Безопасность и приватность

- Content-Security-Policy в `index.html`: скрипты только свои, картинки только свои и data:, сеть только к двум словарным сервисам. Сторонний код на страницу попасть не может.
- Шрифты лежат в репо, к Google Fonts запросов нет. Единственный внешний трафик: слово, по которому ты нажал в английской книге, уходит в Free Dictionary API и MyMemory.
- `referrer: no-referrer`: внешние словари не узнают адрес твоего сайта.
- Все, что ты вводишь, и все, что приходит из книг, экранируется перед показом; разметка EPUB и FB2 пропускается через белый список тегов без атрибутов, PDF разбирается в текст.
- Резервная копия при загрузке проверяется по типам, чужие или битые поля отбрасываются.

Цитаты древних авторов даны в вольном переводе, идеи современных авторов пересказаны своими словами.
